도트랩 (DotLab)
그리면서 생성하는 픽셀아트 에디터

직접 한 칸씩 찍는 도트 에디터에, 프롬프트로 스프라이트를 만들어 주는 AI 생성을 붙인 웹 도구입니다. 생성 결과가 그대로 편집 가능한 픽셀 레이어로 들어온다는 점이 핵심입니다.

제품명 가칭플랫폼 웹 (데스크톱 우선)작성일 2026.10.01상태 초안 · 경쟁 분석 반영

01한 줄 정의

AI가 그린 "픽셀풍 그림"이 아니라, 그리드에 정확히 맞고 팔레트가 정리된 "진짜 도트"를 만들어 주고, 사용자가 바로 이어서 손으로 다듬을 수 있게 한다.

02배경과 문제

픽셀아트를 만드는 사람은 지금 두 종류의 도구를 오가며 작업합니다. 전문 도트 에디터는 손작업에 강하지만 빈 캔버스에서 시작해야 하고, 범용 AI 이미지 생성기는 빠르지만 결과물이 도트 작업에 바로 쓰이지 않습니다.

문제 1

AI 결과물이 진짜 도트가 아니다

픽셀 크기가 들쭉날쭉하고 그리드에 맞지 않으며, 안티앨리어싱과 수백 가지 색이 섞여 있어 게임 에셋으로 쓰려면 사실상 다시 그려야 합니다.

문제 2

생성과 편집이 끊겨 있다

생성 → 다운로드 → 축소 → 색 줄이기 → 에디터로 불러오기 과정을 여러 도구에서 반복합니다. 일부만 다시 만들고 싶어도 전체를 다시 생성해야 합니다.

문제 3

입문 장벽이 높다

초보자는 빈 16×16 캔버스 앞에서 막힙니다. 참고할 초안이 있으면 형태와 명암을 배우며 수정하는 방식으로 훨씬 쉽게 시작할 수 있습니다.

03경쟁 제품 분석

픽셀아트 도구는 크게 손으로 그리는 에디터(Aseprite, Pixelorama, Piskel, Pixquare, Resprite)와 AI 생성 도구(PixelLab, Retro Diffusion)로 나뉩니다. AI 도구는 대부분 기존 에디터의 확장이나 연동 형태로 붙어 있어, 생성과 편집이 한 제품 안에서 설계된 경우는 드뭅니다.

Aseprite

사실상 업계 표준 데스크톱 에디터

타임라인·어니언 스킨 중심의 애니메이션, 인덱스 컬러 모드, 픽셀 퍼펙트 브러시, 픽셀아트용 회전(RotSprite), 타일 모드, 스프라이트 시트 + JSON 아틀라스 내보내기. Lua 스크립트와 확장 생태계가 강점이고 AI 생성도 확장으로 붙습니다.

Pixelorama

무료 오픈소스 (MIT), 웹 지원

클리핑 마스크와 레이어 효과(외곽선·그라디언트·그림자), 사각·아이소·헥스 타일맵, 3D 레이어, 오디오 싱크 애니메이션, 동영상 내보내기, 명령줄 일괄 내보내기, 자동 백업, 확장 기능을 지원합니다.

Piskel

가벼운 무료 웹 에디터 (Apache)

기본 도구, 대칭, 디더링, 실시간 애니메이션 미리보기와 어니언 스킨, GIF·스프라이트 시트 내보내기, 공개·비공개 갤러리 공유. 입문자 진입이 쉬운 대신 고급 기능은 적습니다.

Pixquare

iPad·iPhone 특화

Apple Pencil·제스처 최적화, 레퍼런스 레이어, 알파 잠금, 블렌드 모드, 링크된 셀과 프레임 태그, 타일맵, 무제한 축 대칭, 커스텀 브러시, Aseprite 파일 호환, Lospec 팔레트 연동, 타임랩스 녹화, 왼손 모드.

Resprite

모바일+데스크톱 크로스플랫폼

비파괴 레이어 스타일(외곽선·그림자), 지형 규칙 기반 자동 타일링, 픽셀 텍스트 도구, Aseprite·PSD 가져오기/내보내기, Tiled 맵 호환, 커서 파일·비즈 도안 내보내기 같은 틈새 출력까지 지원합니다.

PixelLab

게임 에셋용 AI 생성 (가장 가까운 경쟁자)

텍스트→스프라이트, 4·8방향 캐릭터 회전, 텍스트·스켈레톤 기반 애니메이션, 인페인팅, 스타일 레퍼런스, 타일셋·맵 생성. 편집은 Aseprite 확장과 Pixelorama 기반 웹 에디터 연동으로 제공하며 구독·크레딧 과금입니다.

Retro Diffusion

Aseprite 안에서 쓰는 AI 생성

픽셀아트 전용 자체 모델, 스마트 색 감소와 텍스트로 팔레트 만들기, 참조 이미지 색감을 옮기는 컬러 스타일 트랜스퍼, 오픈포즈 스켈레톤 포즈 에디터와 ControlNet 기반 생성을 제공합니다.

분석에서 얻은 시사점

기본기

에디터 기본기는 협상 불가

픽셀 퍼펙트, 인덱스 컬러, 어니언 스킨, 스프라이트 시트+JSON은 모든 주요 에디터가 갖춘 기본값입니다. 이게 빠지면 AI 기능이 좋아도 숙련자는 남지 않습니다.

전환 비용

.aseprite 호환이 이주의 열쇠

Pixquare와 Resprite는 Aseprite 파일 호환으로 기존 사용자를 데려옵니다. 도트랩도 가져오기/내보내기를 지원해 "Aseprite와 같이 쓰는 도구"로 진입합니다.

차별화

PixelLab과의 차이를 분명히

PixelLab은 생성 기능이 강하지만 편집은 외부 에디터 연동입니다. 도트랩은 생성 결과가 처음부터 인덱스 팔레트 레이어로 들어오고, 부분 재생성·팔레트 고정이 에디터 도구처럼 동작하는 "한 몸" 경험으로 차별화합니다.

틈새

작지만 사랑받는 출력 기능

타임랩스 녹화, 비즈·자수 도안, 고배율 GIF처럼 크리에이터가 SNS에 바로 올리는 출력이 확산 경로가 됩니다. 비용이 낮아 V1에 넣을 가치가 있습니다.

08AI 생성 방식

이미지 생성 모델만으로는 그리드가 맞는 도트를 안정적으로 얻기 어렵습니다. 그래서 생성 모델 + 픽셀화 후처리 파이프라인을 하나의 기능으로 묶고, 후처리 품질을 제품 경쟁력의 중심에 둡니다.

STEP 1생성픽셀아트 스타일에 특화된 이미지 모델(외부 API 또는 자체 파인튜닝)로 고해상도 생성
STEP 2그리드 추정생성 이미지의 실제 픽셀 크기와 오프셋을 찾아 목표 해상도로 정렬
STEP 3다운샘플블록 단위 최빈색(mode)으로 축소해 번진 경계 제거
STEP 4팔레트 양자화지정 색 수로 줄이거나 사용자 팔레트에 강제 매핑
STEP 5정리배경 제거, 고립 픽셀 제거, 외곽선 1px 정리
  • MVP 전략: 외부 이미지 생성 API를 사용하고 STEP 2~5를 자체 구현합니다. 모델 학습 비용 없이 빠르게 검증할 수 있습니다.
  • 이후 전략: 사용량과 품질 데이터가 쌓이면 픽셀아트 전용 LoRA 등으로 자체 모델을 만들어 원가와 스타일 일관성을 개선합니다.
  • 이미지 → 도트 변환은 STEP 2~5만 사용하므로 서버 GPU 없이 브라우저에서 처리할 수 있습니다(무료 기능 후보).

13리스크와 대응

리스크영향대응
생성 품질이 기대에 못 미침높음후처리 파이프라인에 집중 투자, 작은 해상도(16~64px)에 기능 범위를 한정해 품질 확보
생성 원가가 수익보다 큼높음크레딧 제도, 후보 수 조절, 이미지→도트는 클라이언트 처리, 장기적으로 자체 모델
저작권·학습 데이터 논란중간학습 데이터 출처가 명확한 모델 선택, 상업적 사용 조건 약관 명시, 특정 작품·캐릭터 모방 프롬프트 필터
도트 작가 커뮤니티의 반감중간"대체"가 아닌 "초안·보조" 포지셔닝, 에디터 단독으로도 충분히 좋은 도구로 만들기
PixelLab 등 AI 도구와 정면 경쟁높음생성 결과가 인덱스 팔레트 레이어로 바로 들어오는 통합 편집 경험, 한국어 프롬프트·한글 도트 폰트 등 현지화, 무료 이미지→도트로 유입
기존 에디터 사용자의 이탈 비용중간.aseprite 호환으로 함께 쓰는 도구로 진입, 단축키 프리셋을 Aseprite와 맞춤

14결정이 필요한 사항

  1. 첫 출시를 웹 단독으로 할지, 데스크톱 앱(오프라인)을 함께 낼지
  2. MVP의 생성 엔진으로 어떤 외부 API를 쓸지, 처음부터 자체 모델을 준비할지
  3. 타깃을 게임 개발자 중심으로 좁힐지, 입문자·크리에이터까지 넓게 잡을지 (기능 우선순위가 달라짐)
  4. 무료 플랜의 생성 크레딧 양과 Pro 가격대
  5. 모바일·태블릿(펜 입력) 지원 시점. Pixquare·Resprite가 선점한 영역이라 늦게 들어갈지, 웹 반응형으로 일찍 대응할지
  6. .aseprite 호환을 MVP로 앞당길지 (기존 사용자 확보 vs 개발 기간)
