# 도트랩 DotLab

직접 한 칸씩 찍는 도트 에디터에 AI 생성과 이미지 → 도트 변환을 붙인 픽셀아트 도구입니다. 웹 페이지와 Figma 플러그인 두 가지로 빌드됩니다.

## 시작하기

```bash
npm install
npx playwright install chromium   # 테스트를 돌릴 때만 필요
npm run build                     # dist/web/dotlab.html, dist/figma/
npm test
```

- **바로 쓰기**: https://untitledjay.github.io/dotlab/ (GitHub Pages. AI 생성은 Claude 아티팩트 버전과 Figma 플러그인에서 씁니다)
- **웹 버전**: `dist/web/dotlab.html`을 브라우저로 열면 에디터와 이미지 변환을 바로 쓸 수 있습니다. AI 생성은 Claude 아티팩트로 게시했을 때 동작합니다(기능 `sample`, `downloads`).
- **Figma 플러그인**: Figma 데스크톱 앱에서 Plugins → Development → Import plugin from manifest…로 `dist/figma/manifest.json`을 고릅니다. 자세한 사용법은 `figma/README.md`에 있습니다.

## 주요 기능

- **그리기**: 연필(픽셀 퍼펙트), 지우개, 채우기, 스포이드, 직선·사각형·원, 선택·마술봉·이동, 대칭, 디더, 타일 모드
- **팔레트와 레이어**: 인덱스 컬러 팔레트(최대 62색, 프리셋·램프·가져오기), 팔레트 모음(지금 팔레트·저장한 팔레트·프리셋을 나란히 보고 색 가져오기), 레이어(잠금, 알파 잠금, 불투명도, 외곽선 효과)
- **UI 컴포넌트 모드**: 버튼·패널·입력칸·체크박스·토글·진행 바·탭·말풍선 템플릿과 모양 옵션(크기·모서리 둥글기·테두리·입체감), 상태(기본·호버·누름·비활성), 9-slice 가이드·모서리 잠금(안쪽만 그리기)·안쪽 영역, 늘린 미리보기, 내 컴포넌트 라이브러리, 상태별 PNG + 9-slice JSON + CSS 내보내기, Figma에 상태별 변형을 가진 컴포넌트로 넣기
- **애니메이션**: 프레임, 링크 셀(여러 프레임이 같은 그림 공유), 태그(정방향·역방향·핑퐁, 태그 범위만 재생), 어니언 스킨
- **AI**: 텍스트로 도트 생성, 선택 영역 다시 그리기, 문장으로 팔레트 만들기
- **이미지 → 도트**: 확대·압축된 도트 이미지에서 원래 픽셀 격자를 자동으로 찾아 복원
- **참조 이미지**: 캔버스에 겹쳐 띄우기, 색감을 팔레트에 옮기기
- **파일**: `.aseprite` 열기·저장(레이어·프레임·태그·링크 셀 보존), PNG, GIF(태그 범위 선택), 스프라이트 시트 + JSON(Aseprite 형식 태그 포함), 타임랩스 GIF, 프로젝트 파일
- **Figma 연동**: 벡터·PNG로 넣기, 다시 열어 편집 후 제자리 교체, 선택 레이어 가져오기, 팔레트를 색 스타일로 저장
- **열린 캔버스**: 여러 캔버스를 탭으로 열어 두고 오가기(탭마다 실행 취소·화면 위치 유지, 닫았다 열어도 모든 탭 복원)
- **화면**: 한국어 / English 전환, 기본 라이트(화이트) 모드와 다크 모드 버튼(시스템 설정과 상관없이 라이트로 시작, 선택은 기억)
